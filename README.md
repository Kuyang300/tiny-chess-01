A chess engine in 4 KB of Python: negamax with alpha-beta, quiescence
search, a transposition table, killer moves and MVV-LVA ordering, with a
fixed 100,000-node budget per move. No model calls, no clock — the same
position always gets the same move.

## Run it

    python3 main.py

It plays the make.fun gauntlet through the env at $MAKEFUN_ENV_URL.
